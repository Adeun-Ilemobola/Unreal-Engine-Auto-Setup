# Code quality and maintainability

Confidence terms throughout this audit are: **Confirmed by source code or tests**, **Strongly indicated but not yet reproduced**, and **Requires further investigation**. Source-confirmed design limitations are distinguished from demonstrated end-user failures.

## Overall assessment

The code already separates pure planners/parsers from UI and filesystem/process adapters. There are no npm runtime dependencies and no detected static local-import cycles. Existing safety checks and tests are valuable; a rewrite or framework migration would add risk without addressing the principal defects.

The largest file by physical lines is `runner.js` (169), followed by `extension.js` (158) and `dependencyActions.js` (154). Those counts conceal dense statements: `runtimeCoordinator.js` compresses a state machine into 49 lines, and `sidebar.js` compresses eight view sections into 25. Complexity is concentrated in long closures and multi-action lines rather than unusually large files.

## Parser boundaries

`buildCsParser.js:31–79` deliberately accepts a small conventional ModuleRules grammar. Conditional/computed/helper-based rules become read-only. That is a good safety boundary: do not replace it with unrestricted regex rewriting or execute project C# to obtain a model. `descriptors.js` preserves unrelated JSON bytes and rejects duplicate keys.

Target parsing is less careful: `project.js:13–16` strips comments but leaves strings, then searches assignments. A disposable probe containing only `string Note = "Type = TargetType.Editor";` reported an Editor target. This is **confirmed by tests run in this audit** (F05); invalid target-type inference can affect Run selection. The remedy can be a small literal-aware scanner or reuse of a suitable existing lexer; a full C# parser dependency is not required.

Comments should continue explaining constraints (why no external Live Coding trigger, why generation preserves files, why edits stay unsaved). Add transition invariants where concurrency is non-obvious; do not add line-by-line narration of ordinary assignments.
